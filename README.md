# C++ Projects

A collection of C++ projects from my BSc in Information Technology, demonstrating OOP, data structures, STL containers, and memory management.

**Tech Stack:** C++17 • STL • File I/O • OOP • Linked Lists • Priority Queues

**Compile any project:**
```g++ -std=c++17 -o output filename.cpp && ./output```

---

## Projects

### 1. ClubHub Basic — `ClubHub_Basic.cpp`
Student club management system using STL map, set, and vector. Supports memberships, alphabetical sorting, and club queries.

### 2. ClubHub Advanced — `ClubHub_Advanced.cpp`
Extended ClubHub with file persistence (save/load) and a social graph adjacency list tracking student connections across shared clubs.

### 3. Course Registration Scheduler — `Course_Registration_Scheduler.cpp`
Priority queue-based enrollment system favouring senior students. Auto-assigns rooms and generates personalised schedules.

### 4. Library Catalog System — `Library_Catalog_System.cpp`
CLI library manager for books, journals, and digital resources. Uses inheritance, smart pointers, and lambda functions.

### 5. Support Ticket System — `Support_Tickets.cpp`
Customer support tracker built as a singly linked list from scratch with full CRUD operations and manual memory management.
